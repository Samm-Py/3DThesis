# Legacy raster-optimization prototypes

This directory contains the original optimization experiments and is retained
for provenance. It is not the canonical publication workflow and some scripts
mutate `3DThesis/TestInputs` in place.

Use [`../melt_pool_demos/`](../melt_pool_demos/README.md) for the self-contained
single-track, raster, square, and triangle studies. Shared scan and isosurface
measurement utilities used by those studies now live in
`melt_pool_demos/common/`.
