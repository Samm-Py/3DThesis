# Two-track figures

The paper uses three figures, retained as vector PDFs:

- `twotrack_base_maps`: nominal and optimized solidification-gradient maps;
- `twotrack_base_controls`: optimized power, sigma, and velocity history;
- `twotrack_base_traces`: nominal and optimized width/depth traces.

Generate them with:

```bash
python make_publication_figures.py
```
